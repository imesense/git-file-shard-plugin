# Стиль кодирования

[English](./python-coding-style.md) | Русский

Этот документ определяет стандарты кодирования для проекта.
Этот стандарт разработан для стиля кода Python.

## Соглашения о файлах

- Стандартное расширение файлов для файлов Python - это `py`.
- Название файла должно точно соответствовать названию модуля.
- Файлы должны быть сохранены в кодировке __UTF-8__ с окончанием строк __LF__ и должны заканчиваться одной пустой строкой.

## Соглашения об именовании

- Названия пакетов и модулей должны быть в единственном числе и в __Lower Case__.
- Название класса должно быть написано в __Pascal Case__.
  - Тестовый класс должен иметь постфикс `Test`.
- Названия констант должны быть написаны заглавными буквами в __Snake Case__.
- Названия переменных и функций должны быть в __Snake Case__.
- Названия приватных членов должны иметь префикс `_`.

## Форматирование кода

- Не более 120 символов в строке.
- Используйте 4 пробела вместо табуляций.
- Используйте одинарные кавычки для строковых литералов и f-строки для интерполяции.
- Используйте тройные двойные кавычки для документации всех публичных функций.
- Используйте 1 пробел между ключевым словом и условием.

## Рекомендации

- Используйте правила группировки и разделяйте импорты:
  - Стандартная библиотека (`os`, `hashlib`, `argparse`).
  - Сторонние зависимости.
  - Проектно-специфичные (`git_file_shard.*`).
- Используйте одну пустую строку между группами импортов.
- Предпочитайте стиль `from os import path` для часто используемых подмодулей.
- Выводите пользовательские сообщения через `print()` и используйте префиксы `Error:` / `Warning:`.
- Разбирайте аргументы командной строки через подкоманды `argparse` и сохраняйте новые флаги совместимыми с существующими (`--repo`, `--threshold`, `--md5`).
